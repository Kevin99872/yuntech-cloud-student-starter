# 平台公開契約

情境：10 台合成設備上報 100 筆事件；值班者查看影像，更新狀態並查歷程。
這是功能測資規模，不是效能承諾。禁止真實學籍或個資。

基本介面（可擴充；變更時更新契約與測試）：

| 操作 | 最低契約 |
|---|---|
| GET /health | 200；不得洩漏密碼／環境變數 |
| POST /events | reporter；event_id、device_id、observed_at、type；成功 201，相同內容重送 200，不新增一筆 |
| 衝突 event_id | 相同 ID 不同內容 409；無效輸入 400 |
| GET /events、GET /events/{id} | operator；分頁／設備篩選；不存在 404 |
| PATCH /events/{id}/status | operator；new → acknowledged → resolved；非法轉換 409，保留 actor/time/history |
| 事件附件 | 綁定既有事件；JPEG/PNG 不超過 1 MiB；私有 S3；授權後短效 URL 在程式中使用 |
| 認證 | 缺少／無效認證 401；合法身分無權操作 403；不把裝置憑證當人員登入 |
| SQL | 設備、事件、附件metadata、處理歷程；外鍵／唯一鍵／交易與參數化 SQL |
| 可靠性 | 有限佇列、退避重試、重啟持久、備份恢復比對 |

先在 src/ 實作並加測試；部署方法由你編寫，需可從鎖定版本重建。
公共 HTTPS 必須驗證名稱與可信鏈；課內私有 CA 要明示信任設定及適用範圍，不能宣稱為公認憑證。
DB 只接受同一帳號 VPC 中核准應用來源；不可假設能連其他學生／教師帳號的私有 DB。
學習進度循序增加，不要求 W4 一次完成資料库、MQTT、影像與監控。
