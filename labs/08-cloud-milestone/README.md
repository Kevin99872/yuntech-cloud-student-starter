# W8–W9：雲端系統里程碑

目標：交付校園設備巡檢與異常事件平台：設備 → 事件 → 影像 → 查詢 → 處理狀態／歷程。

前置：完成上一階段或由 Git／備份重建；身分驗證通過；填妥本次資源與回收清單。

方法：整合既有模組；使用 10 台模擬設備、100 筆合成事件。自行編寫部署和驗收；不再增加無必要的 AWS 服務。

公開驗收：完整 UI 情境、兩角色邊界、重複／錯誤事件、服務重啟、成本與精確回收。現場接受一項需求變更並解釋修正。

交付：自己的程式與設定、可重現步驟、成功與拒絕／故障證據、一次修正及原因、成本與回收證據。
