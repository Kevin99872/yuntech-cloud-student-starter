貼上重啟前、重啟後用 operator 權杖查 `GET /events` 的輸出（只留筆數或 `event_id`，不要貼權杖）：

```text

```

## 2. T2 建資料庫

貼上 `db-up.sh` 結束時的讀回（RDS ID 只留末四碼）：

```text
RDS status=available publicly_accessible=false id_suffix=n-db
```

- [x] 狀態是 `available`
- [x] `PubliclyAccessible` 是 `false`

貼上從 Codespace 測 5432 的輸出：

```text
連不到：符合私有資料庫設計
```

`db-up.sh` 審查紀錄（對照 README 五條）：

| 規格 | Copilot 第一版 | 沒過的話，你請它怎麼改 |
|---|---|---|
| 1. 兩個私有子網、不同 AZ、明確關聯只有 local 的路由表 | 沒過 | 將 `--map-public-ip-on-launch false` 改為 `--no-map-public-ip-on-launch`，並補上已建立子網的路由表關聯。 |
| 2. SG-db 只有 5432，來源＝主機的 SG | 過 | 不需修改；確認入站只有 TCP 5432，來源是主機 SG。 |
| 3. RDS 規格（db.t3.micro、20 GiB、不公開、加密、單一 AZ） | 過 | 不需修改。 |
| 4. 密碼寫進 `.local/db.env`（600），不顯示、不進命令列 | 沒過 | 不把密碼放在 `--master-user-password` 命令列；改用權限 600 的暫存 JSON 或安全輸入，並將 `.local/db.env` 設為 600。 |
| 5. ID 寫進 `.local/resources.json`；讀回 available 與不公開 | 過 | 不需修改；本次另以 `describe-db-instances` 完成最終讀回。 |

資料庫從開始建立到 `available` 大約幾分鐘：7 min
